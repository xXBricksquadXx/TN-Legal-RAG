# Tenn. Code Ann. § 10-7-602 — Open Appointments Act; definitions (agency)

## Plain-language rule

- Defines “agency” for purposes of the Open Appointments Act, generally focusing on entities exercising **state-wide jurisdiction** (subject to statutory details).
- Specifies entities or roles the definition **does not include**, including certain **ex officio** positions or excluded categories as stated in the statute.

## Practice notes

- Useful for determining whether an appointment falls under the Open Appointments Act’s disclosure and process requirements.
- Pair with the specific Open Appointments Act provisions that apply once an entity qualifies as an “agency.”
