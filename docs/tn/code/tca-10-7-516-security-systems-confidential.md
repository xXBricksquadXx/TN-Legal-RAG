# Tenn. Code Ann. § 10-7-516 — Security systems; records confidential

## Plain-language rule

- Certain security system records held by a governmental entity are **confidential** and **not be open** to public inspection under this section (subject to the statute’s specific scope and exceptions).

## Practice notes

- Often cited for building security plans, security camera system specifications, vulnerability assessments, and similar records.
- Pair with other confidentiality provisions and agency-specific security statutes.
