# Tenn. Code Ann. § 10-7-515 — Register of deeds; PII; refusal to record; redaction request

## Plain-language rule

- The register of deeds **should not refuse to record** an otherwise recordable instrument **because it contains personally identifying information** (commonly: SSNs).
- The statute is commonly used alongside a **request to redact personally identifying information** from a recorded document (often excluding certain **microfilm** records depending on local process).
